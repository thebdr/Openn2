# P-014 — evidence / lab notebook

## 2026-07-16 — the vision statement (user) + the vision piece

**The user's vision, verbatim essence:** "code is the best type of manual, help or guide. This app is
fully open, and an executable exists only so that users don't need to install anything. In my vision,
all software should be shipped like this." — This RESOLVES P-014's open licensing question: **fully
open by design**; the exe is a zero-install convenience, not a boundary. One guard adopted: the exe
build pins a version stamp so a modified copy is distinguishable from a release.

**The vision piece** (reviewable artifact, drafted 2026-07-16):
https://claude.ai/code/artifact/dcb272a2-aa05-40d3-bc55-0ed1443d1f00 — demonstrates on REAL PL5
modules (`kernel/content_hash.py`, the staging `_dup_type_index_findings` check) what manual-grade
source reads like, the peek-code flow from a log line, the generated map as the explorer's home, and
the costs stated plainly (hand-written docstrings; two small provenance indexes; fully-open source).

**The M1–M6 commenting standard** (proposed there, pending the user's verdict):
- M1 module docstring = a chapter: what this is FOR THE READER, why, where you meet it in the app.
- M2 every public function = a recipe: what you get, what to pass, a runnable example when non-obvious.
- M3 comments answer WHY in domain language, never narrate syntax.
- M4 every module declares its place in the flow: SSOT tables read/written, the phase button that runs
  it — the anchors peek-code and the map generate from.
- M5 cross-references are links (one src:// + guide:// scheme everywhere), not prose.
- M6 decisions carry their history: what was decided and why, so readers never re-litigate blind.

**Design consequence reaffirmed:** structure-light (P-008 R2–R5 enforcement contracts kept, invisible;
navigability carried by the map + peek-code, so folder perfectionism dropped). The F1 guide narrows to
the operator path; depth lives in the source (shrinks P-006).

**Status:** vision presented; the user is forming their verdict on the combined path
(structure dial + P-014 investment). Nothing implemented yet.
